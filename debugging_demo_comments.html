What is debugging?

Debugging is the process of finding, understanding, and fixing errors in a program. A breakpoint pauses execution at a line so you can inspect the program's state.

1. Reproduce the problem2. Set a breakpoint3. Step through code4. Inspect variables5. Fix and retest

Classroom discussion

Ask students: What should the program print? Which line contains the bug? What values do you see as you step through the code? Why is the output wrong?

Teaching tip: Run the broken program first. Reset, click beside line 5 to set a breakpoint, then use Step to inspect the calculation. Finally click Fix bug and run it again.
